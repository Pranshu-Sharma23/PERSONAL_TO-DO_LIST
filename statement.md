# Project Statement

## Project Title
Personal To-Do Manager

## Problem Statement
Students and individuals often need a simple way to organize daily tasks, identify priorities, track completed work, and review their progress. Managing tasks manually can make it difficult to find pending work or understand overall completion.

The Personal To-Do Manager provides a simple console-based Python solution for creating, organizing, updating, searching, filtering, and tracking tasks.

## Scope
The current project covers:
- Creating tasks
- Viewing tasks
- Editing tasks
- Deleting tasks
- Marking tasks as completed
- Assigning categories
- Assigning priorities
- Searching and filtering
- Viewing basic statistics

The current version intentionally uses only in-memory Python lists. It does not provide permanent data storage.

## Target Users
- Students
- Beginners learning Python
- Individuals managing personal tasks

## High-Level Features
- Task creation and management
- Priority management
- Category management
- Completion tracking
- Search and filtering
- Statistics and reporting
- Input validation
- Unit testing

## Technical Approach
The project is divided into small Python modules to demonstrate modular programming, functions, classes, list processing, validation, and testing.
